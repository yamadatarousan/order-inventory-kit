# ユーザーストーリー（標準ECベース）

## 目的
- 標準ECとして必要なユーザー体験を先に網羅する
- 実装順序とは分離して、仕様漏れ検出の基準を固定する
- `contracts/openapi.yaml` / `docs/spec.md` / `docs/plan.md` の判断根拠をそろえる

## 運用方針
- 本書は「今作る範囲」ではなく「最終的に必要なストーリー全体」を先に記述する
- 各ストーリーに `scope_now` を付け、現時点での実装対象かどうかを明示する
- `scope_now = no` のストーリーも削除しない
- 実装タスクは必ずストーリーIDを参照して作る

## ステータス定義
- `scope_now: yes` 現在の実装対象
- `scope_now: no` 後続実装対象（仕様は先に固定済み）
